# Customer Behavior Analytics

## Project Overview

This project analyzes customer shopping behavior using Python and SQL to uncover purchasing trends, customer preferences, spending patterns, and key revenue-driving factors.

The project began with data cleaning and exploratory data analysis (EDA) in Python, followed by SQL-based business analysis to answer real-world customer and sales questions. The insights generated can help businesses improve customer targeting, marketing strategies, product offerings, and customer retention initiatives.

---

## Project Workflow

### 1. Data Cleaning & Preparation (Python)

Using **Pandas** and **NumPy**, the dataset was prepared for analysis by:

- Checking data quality
- Handling missing values
- Removing duplicates
- Standardizing data formats
- Creating derived features such as age groups
- Preparing the dataset for analytical querying

### 2. Exploratory Data Analysis (Python)

Conducted EDA to better understand:

- Customer demographics
- Purchase amount distributions
- Product popularity
- Customer review trends
- Subscription behavior
- Discount usage patterns

### 3. Business Analysis (SQL)

Performed SQL querying to answer key business questions and generate actionable insights.

---

## Key Business Questions Answered

### Revenue Analysis

- What is the total revenue generated by male versus female customers?
- What is the revenue contribution of different age groups?
- Do subscribed customers spend more than non-subscribed customers?

### Customer Behavior Analysis

- Which customers used discounts but still spent above the average purchase amount?
- Are repeat buyers more likely to subscribe?
- How can customers be segmented into New, Returning, and Loyal groups based on previous purchases?

### Product Performance Analysis

- Which products have the highest average customer ratings?
- What are the most purchased products within each category?
- Which products have the highest percentage of discounted purchases?

### Sales & Marketing Analysis

- How do discounts influence purchasing behavior?
- Which products are most frequently purchased with discounts?
- How does customer spending differ between Standard and Express shipping methods?
